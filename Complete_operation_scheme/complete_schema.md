| ID | Operation | Precondition | Input | Postcondition |
|---|---|---|---|---|
| OP-01 | runSelfCheck | System is powered on and in initialization state. | Diagnostics test signals from sensors and control hardware | If all essential sensors and control devices pass: system transitions to MONITORING mode. Otherwise: system logs failure codes and refuses operational transition. |
| OP-02 | saveArtifactInfo | System is in MONITORING mode; artifact is placed in chamber. | "artifactId, safe limits: (Tmin,Tmax,Hmin,Hmax,Vmax,Lmax)" | Artifact profile is stored in memory; system sets artifactPresent = true and starts active tracking of artifact conditions. |
| OP-03 | startConservation | Profile is loaded (artifactPresent == true); door sensor detects CLOSED; system is in MONITORING mode. | "Door sensor state (CLOSED), active artifact profile" | System transitions from MONITORING to CONSERVATION_ACTIVE mode; begins active regulation routines. |
| OP-04 | readSensors | System is powered and running in an active operational mode. | "Raw telemetry streams (temperature, humidity, light, vibration, door, power)" | Latest readings are captured, normalized, timestamped, and made available for limit evaluations. |
| OP-05 | checkLimits | Mode is CONSERVATION_ACTIVE; valid sensor readings and loaded profile exist. | "Current readings: Tcurr,Hcurr,Vcurr,Lcurr, safe limits" | Identifies any variance outside allowable ranges; flags specific parameter breaches to trigger corresponding correction operations. |
| OP-06 | fixTemperature | System is in CONSERVATION_ACTIVE; Tcurr<Tmin OR Tcurr>Tmax. | "Tcurr, target range [Tmin,Tmax]" | Heating or cooling actuator command is issued; a recovery timer is started to monitor the thermal correction window. |
| OP-07 | fixHumidity | System is in CONSERVATION_ACTIVE; Hcurr<Hmin OR Hcurr>Hmax. | "Hcurr, target range [Hmin,Hmax]" | Humidifier or dehumidifier actuator command is issued; a recovery timer is started to track humidity restoration. |
| OP-08 | confirmStable | A correction command was issued or a disturbance occurred; parameter value has re-entered target range. | "Real-time sensor stream for parameter, required stabilization duration tstable" | If parameter stays within bounds continuously for tstable: condition is marked verified/safe. If it deviates again: stabilization resets and fails. |
| OP-09 | triggerProtection | Parameter remains out of range and recovery time exceeds maximum allowed limit (telapsed>tallowed). | "Failed parameter name, current environmental readings" | System transitions to PROTECTION_MODE; reduces light levels; engages auxiliary environmental controls; invokes alertStaff. |
| OP-10 | alertStaff | "An unresolved anomaly, mode escalation, or critical hardware/power failure is detected." | "Alert event code, severity level, diagnostic message" | High-priority notification and event data are delivered to the museum operator console and logged. |
